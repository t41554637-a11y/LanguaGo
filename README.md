# LanguaGo

Прототип языкового приложения на SwiftUI: четыре языка, озвучка, словарь, Дино, локальный прогресс и здоровые перерывы.

## Запуск

Нужен Mac с Xcode 16 или новее. Скачайте репозиторий, откройте LanguaGo.xcodeproj, выберите схему LanguaGo и iPhone-симулятор, нажмите Run. Не создавайте второй проект и не добавляйте повторно файлы.

## Статус

Сборка и запуск не проверены. Это исходники прототипа, не готовое приложение из App Store. Иконка и тесты отсутствуют. В текущей логике серия не сбрасывается после пропуска дня; повторное прохождение может создавать дубликаты слов. Пока доступны семь демонстрационных фраз.

Для установки на личный iPhone настройте Signing & Capabilities своей командой и уникальным Bundle Identifier.
